## Projects

### [PuriSound](https://github.com/melody3212/PuriSound) · 대표 프로젝트
**LG DX School** · 생활 밀착형 스마트 소음 케어  
🏆 LG전자 DX School 최우수상

층간·생활 소음에 대한 VOC를 바탕으로 서비스 방향을 설계하고,  
Raspberry Pi 위에서 **실시간 감지 → 마스킹 재생 → LED 피드백 → 클라우드·앱 연동**까지 한 흐름으로 구현한 프로젝트입니다.

완전 차단이 어려운 생활 소음 문제를, “맞춤 대응 사운드와 자동 개입”으로 완화하는 것을 목표로 했습니다.

**기여**
- 네이버 카페·지식인 VOC 크롤링
- Raspberry Pi 파이프라인 전반 (마이크 입력, FFT 분석, 마스킹 결정, 재생, LED, Firebase 연동 및 운영 구성)
- 앱 설정과 디바이스가 맞물려 동작하도록 엣지 측 연동 담당

**기술** · Python, Raspberry Pi, FFT, YAMNet, Firebase, Flutter(프로토타입)
